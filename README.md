## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/vinitdharmale465-lgtm/My-portfolio.git
   ```

2. Open the project folder:
   ```bash
   cd My-portfolio/portfolio-website
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
